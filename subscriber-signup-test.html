Live requests, volume feedback, saves and show controls need an internet connection: Wi-Fi or cellular. If your tablet has no cellular service, connect it to your phone’s personal hotspot. To read songs without internet, open Performance Settings and prepare this device first.

iPhone · Safari
Open the page in Safari. Tap Share (or Page Menu → Share), then Add to Home Screen. If offered, turn on Open as Web App, then tap Add.

iPad · Safari
Open the page in Safari, tap Share, then View More if needed, then Add to Home Screen. If offered, turn on Open as Web App, then tap Add.

Android · Chrome
Open the page in Chrome. Tap the three-dot menu → Install and create shortcut → Create shortcut → Add. Some versions label this Add to Home screen.
