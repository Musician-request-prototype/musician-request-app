Stay connected at your gig
Live requests, volume feedback, saves and show controls need an internet connection: Wi-Fi or cellular. If your tablet has no cellular service, connect it to your phone’s personal hotspot. To read songs without internet, open Offline Song Library and download this device’s copy first.

Add to your Home Screen

For your performer tools, open your account menu and save that page. Share your audience link with fans instead.

iPhone · Safari
Open the page in Safari. Tap Share (or Page Menu → Share), then Add to Home Screen. If offered, turn on Open as Web App, then tap Add.

iPad · Safari
Open the page in Safari, tap Share, then View More if needed, then Add to Home Screen. If offered, turn on Open as Web App, then tap Add.

Android · Chrome
Open the page in Chrome. Tap the three-dot menu → Install and create shortcut → Create shortcut → Add. Some versions label this Add to Home screen.

Open the new icon once to check it. You may need to sign in again there. Prepare Offline Song Library in this Home Screen app before using it without internet. Live requests and online saves still need a connection.

How do I export from BandHelper?

On bandhelper.com, choose your project, then Admin → Export. Turn off Include Finance Data, tap Continue, and save the JSON file. Choose that file above.

Separate PDFs, images and other attached documents are not inside this JSON. Built-in lyrics and chords are included. Other export formats will be added separately.
