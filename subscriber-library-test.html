Stay connected at your gig
Live requests, volume feedback, saves and show controls need an internet connection: Wi-Fi or cellular. If your tablet has no cellular service, connect it to your phone’s personal hotspot. To read songs without internet, open Performance Settings and prepare this device first.

Add to your Home Screen

For your performer tools, open your main menu and save that page. Share your audience link with fans instead.

iPhone · Safari
Open the page in Safari. Tap Share (or Page Menu → Share), then Add to Home Screen. If offered, turn on Open as Web App, then tap Add.

iPad · Safari
Open the page in Safari, tap Share, then View More if needed, then Add to Home Screen. If offered, turn on Open as Web App, then tap Add.

Android · Chrome
Open the page in Chrome. Tap the three-dot menu → Install and create shortcut → Create shortcut → Add. Some versions label this Add to Home screen.

Export song library

Download your complete saved library, including private lyrics and chord charts, to keep a backup or move to another app. Your songs stay here too. Save any edits first. An internet connection is required.

CSV works with spreadsheets and import tools that accept these columns. For spreadsheet safety, cells that could run as formulas start with an apostrophe. JSON keeps the original text and all saved song fields. Each destination app has its own import requirements; these files may need conversion.

Exports include saved active songs, not deleted songs, show history or device-only preferences such as song timing. Keep these files private if they contain your charts.
